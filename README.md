# 🌐 My Website Project

## 📖 Overview
This is a personal web project I created after a long break from development.  
The goal of this project was to refresh my front-end skills and rebuild my confidence in web design and coding.

The website includes a clean layout, modern design elements, and focuses on functionality and presentation.

## 🧩 Features
- Built using **HTML**, **CSS**, and **JavaScript**
- Includes multiple **card sections** and interactive UI elements
- Designed with a **simple and clean interface**
- **Desktop only** — not yet responsive for mobile or tablet devices

## 💻 Compatibility
🖥️ **Best viewed on desktop browsers**  
📱 *Mobile and tablet support will be added later.*

## 🚀 Future Improvements
- Add **responsive design** for all screen sizes
- Include **animations and hover effects**
- Improve **accessibility and performance**
- Add **dark mode** (optional)
